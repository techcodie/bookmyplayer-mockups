## The 5 AI features proposed

1. **AI Video Skill Analysis** *(flagship)* — frame-by-frame skill report from a 30s clip
2. **WhatsApp AI Engagement** — bot books trials and answers in chat
3. **AI Lead Scoring** — ranks every inquiry High/Medium/Low with reasons
4. **AI-Personalized Feed** — same template, different homepage per user
5. **Academy Co-Pilot** — weekly AI briefings + reply drafts for academies
