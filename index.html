FEATURE 01 · FLAGSHIP

AI Video Skill Analysis

A player uploads a 30-second clip. The system returns a frame-by-frame breakdown — posture, balance, timing, technique — in under 60 seconds, mapped to drills and academies.

• Why it matters: shifts BookMyPlayer from a directory to a digital coach
• Only Indian sports platform doing this well today — long-term moat
• Every analysis becomes proprietary training data
Tech stack I'd use
MediaPipe — pose estimation, runs efficiently on-device
PyTorch — train custom sports-movement models on Indian footage
OpenCV — frame extraction and preprocessing pipeline

FEATURE 02

WhatsApp AI Engagement

Indian parents live on WhatsApp. The bot continues the conversation after the user leaves the website — qualifies intent, books trials, sends reminders. Hands off to a human only when confidence drops.

• Cuts the inquiry → conversion drop-off where most leads are lost today
• Replies in seconds — academies usually take hours
• Grounded in academy data via RAG, not free-form LLM hallucination
Tech stack I'd use
WhatsApp Business API — native to how Indian users already communicate
Claude API + RAG — strong reasoning, grounded in academy DB
Deterministic workflows for booking/reminders — never let the LLM book a slot

FEATURE 03 · ACADEMY-SIDE

AI Lead Scoring & Academy Intelligence

Every inquiry looks the same in a form. Behaviorally, a parent who watched 4 videos and compared 3 academies is nothing like one who bounced after 8 seconds. This view ranks every lead — with reasons academies can trust.

• Academies stop wasting time on tire-kickers
• Serious users get faster replies — better UX both sides
• Explainability is the differentiator — show why, not just the score
Tech stack I'd use
XGBoost — works well on behavioral/tabular data, easy to explain
Scikit-learn — feature engineering and evaluation pipelines
SHAP values — surface the top-3 reasons for each score

• Cold-start handled with onboarding sport preference

FEATURE 05 · ACADEMY-SIDE

Tech stack I'd use
Claude API — strong reasoning for reply drafts and weekly briefings
RAG over academy DB — every output cites their own data
Weekly batch pipeline — real-time isn't needed; weekly is the right cadence

CLOSING

Build order & how I'd measure success

This is the order I'd suggest building in and the kind of outcomes I'd hold these features to.

Suggested build order
1
Video Skill Analysis
Start with one sport (e.g. cricket batting). Get the pose pipeline + skill scoring working narrow before going wide.
2
Lead Scoring
Quickest academy ROI. XGBoost on existing behavioral logs — can be built in parallel with Video Analysis.
3
WhatsApp AI
Best built after Lead Scoring is live — the bot can then prioritize high-intent conversations and hand the rest to academies.
4
Personalized Feed
Needs enough behavior data to be useful — gets stronger once the first three features have been generating signals.
5
Academy Co-Pilot
Built on top of all four — the briefing pulls from lead scores, WhatsApp logs, and homepage analytics. Most valuable once the data layer exists.

PRINCIPLES I'D BUILD BY
Both sides of the marketplace win
Every feature improves player experience AND academy outcomes. If only one side wins, the other leaves.
Data > model
Most AI fails because of poor event tracking, not bad models. I'd invest in instrumentation first.
Ship narrow, then wide
One sport, one workflow, one loop — properly. Then scale. Avoid the "broad but shallow" trap.
Defensibility comes from data
Features get copied. Sports-performance datasets and engagement patterns become the moat.
